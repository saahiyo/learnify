# Learnify

Static multi-page course website built with HTML, CSS, and JavaScript.

## Structure

- `index.html` - landing page and login/signup panel
- `courses.html` - searchable course catalog
- `admission.html` - student admission form
- `payments.html` - payment details and confirmation state
- `auth.html` - full login/signup page
- `about.html`, `services.html`, `contact.html` - supporting pages
- `assets/css/style.css` - shared styling
- `assets/js/main.js` - search, form, and payment interactions
- `assets/js/firebase-auth.js` - Firebase email/password auth
- `assets/images/` - image and QR assets
- `docs/` - project report and blackbook files

## Run

Open `index.html` in a browser, or serve the folder with any static server. Firebase auth needs network access and an authorized domain in the Firebase project settings.
